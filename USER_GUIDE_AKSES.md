## 📱 Langkah-langkah Akses

### 1️⃣ Buka Browser
- Chrome ✅
- Firefox ✅
- Microsoft Edge ✅

### 2️⃣ Ketik URL
```
https://10.62.8.101:8443
```

### 3️⃣ Bypass Security Warning

Browser akan menampilkan warning. **Ini normal untuk aplikasi internal!**

#### Google Chrome / Microsoft Edge:
1. Muncul halaman **"Your connection is not private"**
2. Klik tombol **"Advanced"** (atau **"Tingkat Lanjut"**)
3. Klik link **"Proceed to 10.62.8.101 (unsafe)"** (atau **"Lanjutkan ke 10.62.8.101"**)

#### Mozilla Firefox:
1. Muncul halaman **"Warning: Potential Security Risk Ahead"**
2. Klik tombol **"Advanced"**
3. Klik **"Accept the Risk and Continue"**

### 4️⃣ Login
Masukkan username dan password Zinus IT Anda.

## ❓ FAQ

### Kenapa muncul warning "Not Secure"?
**Jawab:** Ini normal untuk aplikasi internal company. Certificate yang digunakan adalah self-signed certificate khusus untuk jaringan Zinus IT. Data Anda tetap terenkripsi dengan HTTPS.

### Apakah aman?
**Jawab:** Ya, sangat aman untuk digunakan di jaringan internal Zinus IT. Sama seperti Portainer yang sudah Anda gunakan sehari-hari.

### Apakah harus bypass warning setiap kali akses?
**Jawab:** Biasanya browser akan "mengingat" pilihan Anda untuk beberapa waktu. Tapi jika muncul lagi, tinggal klik "Advanced" → "Proceed" seperti biasa.

### Bagaimana kalau lupa password?
**Jawab:** Hubungi IT Department (ext. 123) atau email: it@zinus.co.id

### Bisa diakses dari luar kantor?
**Jawab:** Tidak. Aplikasi ini hanya bisa diakses dari jaringan internal Zinus IT.
