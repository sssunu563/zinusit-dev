🔧 TROUBLESHOOTING:
───────────────────────────────────────────────────────────

Issue: Container won't start
→ docker-compose logs app
→ Check .env has all required variables

Issue: 502 Bad Gateway from NPM
→ Check container is running: docker ps
→ Check port 8001 accessible: curl http://localhost:8001
→ Check NPM can reach: ping 10.62.8.101

Issue: SSL Certificate failed
→ Ensure DNS A record points to server IP
→ Ensure port 80/443 open to Let's Encrypt servers
→ Check domain is publicly accessible

Issue: Laravel still generates http:// URLs
→ Check .env: APP_URL=https://...
→ docker-compose down && docker-compose up -d
→ docker exec zinusit-app php artisan optimize:clear
→ Check TrustProxies middleware active

Issue: Session/Login issues
→ Check SESSION_DOMAIN in .env (should be empty or .zinus.co.id)
→ Clear browser cookies
→ docker exec zinusit-app php artisan cache:clear

🔄 NPM ALTERNATIVE CONFIGS:
───────────────────────────────────────────────────────────

Option 1: Forward to Host IP + Port (Current)
Forward to: 10.62.8.101:8001
✅ Simple
✅ Works even if containers restart

Option 2: Forward to Container IP
Forward to: <container-ip>:80
⚠️ IP might change on restart

Option 3: Connect NPM to same network
# Add NPM container to zinusit-network:
docker network connect zinusit-network nginx-proxy-manager
# Then forward to:
Forward to: zinusit-app:80
✅ Best for production
✅ No port conflicts
