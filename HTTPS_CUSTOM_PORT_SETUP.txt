📋 STEP-BY-STEP DEPLOYMENT:

1️⃣  SSH ke Server:
   ssh root@10.62.8.101

2️⃣  Navigate ke Project:
   cd /home/admin/zinusit-dev

3️⃣  Pull Latest Changes:
   git fetch origin && git reset --hard origin/master

4️⃣  Update .env:
   nano .env
   
   # Update baris ini:
   APP_URL=https://10.62.8.101:8001

5️⃣  Generate SSL Certificate (Self-Signed):
   
   sudo openssl req -new -x509 -days 365 -nodes \
     -out /etc/ssl/certs/zinusit.crt \
     -keyout /etc/ssl/private/zinusit.key \
     -subj "/C=ID/ST=West Java/L=Bogor/O=Zinus/OU=IT/CN=10.62.8.101" \
     -addext "subjectAltName=IP:10.62.8.101,DNS:it.zinus.co.id"
   
   sudo chmod 600 /etc/ssl/private/zinusit.key
   sudo chmod 644 /etc/ssl/certs/zinusit.crt

6️⃣  Update Nginx Config:
   sudo nano /etc/nginx/sites-available/zinusit
   
   # Paste konfigurasi dari nginx_https_custom_port.conf
   # (yang sudah dibuatkan di development)

7️⃣  Enable Site & Test Config:
   sudo ln -sf /etc/nginx/sites-available/zinusit /etc/nginx/sites-enabled/
   sudo nginx -t

8️⃣  Allow Firewall:
   sudo ufw allow 8001/tcp
   sudo ufw status

9️⃣  Restart Services:
   php artisan optimize:clear
   php artisan optimize
   sudo systemctl restart php8.4-fpm
   sudo systemctl restart nginx

🔟  Test Access:
   curl -k -I https://10.62.8.101:8001
   # -k = bypass SSL verification (karena self-signed)

⚠️  IMPORTANT NOTES:
───────────────────────────────────────────────────────────

1. Self-Signed Certificate Warning:
   Browser akan menampilkan warning "Not Secure"
   Klik "Advanced" → "Proceed to site (unsafe)"
   
2. Port 8001 harus dibuka di firewall:
   sudo ufw allow 8001/tcp
   
3. Jika ada load balancer/reverse proxy:
   Pastikan forward ke port 8001 dengan HTTPS
   
4. Session/Cookie Issues:
   Karena pakai IP, pastikan SESSION_DOMAIN kosong di .env:
   SESSION_DOMAIN=

5. Mixed Content:
   Pastikan semua resource (CSS/JS/images) pakai HTTPS

🔧 TROUBLESHOOTING:
───────────────────────────────────────────────────────────

Issue: "Connection Refused"
→ sudo systemctl status nginx
→ sudo netstat -tulpn | grep :8001
→ Check firewall: sudo ufw status

Issue: "SSL Certificate Error"
→ Regenerate certificate dengan SAN (SubjectAltName)
→ Browser: Accept exception untuk self-signed cert

Issue: "Mixed Content Warning"
→ Check browser console
→ Update external URLs ke HTTPS
→ php artisan optimize:clear

Issue: "500 Internal Server Error"
→ tail -f /var/log/nginx/zinusit-error.log
→ tail -f storage/logs/laravel.log
→ Check file permissions: storage/ dan bootstrap/cache/
