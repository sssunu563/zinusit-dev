================================================================================
                              TAHAP 1: LOCAL
================================================================================

Step 1: Buat Perubahan
-----------------------
Buat perubahan kode / feature yang diinginkan.

Bisa:
  $ vim app/Http/Controllers/HomeController.php
  $ npm run build    # Jika ada perubahan frontend

Step 2: Verifikasi Lokal (Optional)
-----------------------
Kalau ingin test dulu sebelum push:

$ npm run build        # Build assets
$ docker compose up    # Start lokal
$ curl http://localhost:8001/up
# Test di browser: http://localhost:8001

Jika OK, lanjut. Jika error, fix dulu.

$ docker compose down  # Stop


================================================================================
                          TAHAP 2: GIT LOCAL
================================================================================

Step 1: Prepare Untuk Commit
-----------------------
$ git status          # Lihat file apa yang berubah

Output contoh:
  modified:   app/Http/Controllers/HomeController.php
  modified:   resources/js/pages/Home.vue

Step 2: Build Frontend (Penting!)
-----------------------
SELALU build frontend sebelum commit:

$ npm run build
$ ls public/build/manifest.json  # Verify ada

JANGAN lupa ini! Kalau lupa, di server akan blank page.

Step 3: Commit
-----------------------
$ git add -A
$ git commit -m "Deskripsi perubahan yang jelas"

Contoh commit messages:
  - "Add new feature: Dashboard widgets"
  - "Fix: LDAP login timeout issue"
  - "Improve: Asset search performance"
  - "Security: Update dependencies"

Step 4: Push ke Git
-----------------------
$ git push -u origin main

Tunggu proses push. Output:
  To github.com:your-org/zinusit.git
     abc1234..def5678  main -> main

Selesai! Kode sekarang di repository.


================================================================================
                           TAHAP 3: SERVER
================================================================================

Step 1: SSH ke Server
-----------------------
$ ssh user@ip-server-kamu
atau
$ ssh -i ~/.ssh/id_key user@ip-server-kamu

Step 2: Navigate ke Project
-----------------------
$ cd /var/www/zinusit

Verifikasi lokasi:
$ pwd
Output: /var/www/zinusit

Step 3: Pull Kode Terbaru
-----------------------
$ git pull

Output:
  remote: Counting objects: 12, done.
  Unpacking objects: 100% (12/12), done.
  updating abc1234..def5678
  Fast-forward
   app/Http/Controllers/HomeController.php | 10 ++++++
   resources/js/pages/Home.vue             | 20 ++++-----
   2 files changed, 15 insertions(+), 5 deletions(-)

Kode terbaru sudah ter-pull dari Git.

Step 4: Verifikasi Perubahan
-----------------------
$ git log -1          # Lihat commit terbaru

Output:
  commit def5678abc...
  Author: Your Name
  Date:   2026-09-03

    Add new feature: Dashboard widgets

Step 5: Build Frontend (Penting!)
-----------------------
$ npm run build

Tunggu sampai selesai:
$ ls public/build/manifest.json  # Harus ada!

Step 6: Deploy
-----------------------
$ bash deploy.sh

Tunggu output:
  [✓] Frontend built
  [✓] Docker image built
  [✓] Containers started
  [✓] Assets copied
  [✓] Deploy selesai!

Step 7: Verifikasi
-----------------------
$ docker compose ps

Semua harus running/healthy:
  NAME               STATUS           
  zinusit-app        running (healthy)
  zinusit-db         running (healthy)
  zinusit-cache      running (healthy)
  zinusit-scheduler  running
  zinusit-queue      running

Step 8: Check Logs
-----------------------
$ docker compose logs app | tail -50

Pastikan TIDAK ada [ERROR]

Verifikasi dari browser atau curl:
$ curl http://localhost:8001/up

================================================================================
                         TROUBLESHOOTING UPDATE
================================================================================

Kalau Build Error:
------------------------------
$ npm install
$ npm run build

Atau clear cache:
$ rm -rf node_modules package-lock.json
$ npm ci
$ npm run build

Kalau Deploy Error:
------------------------------
$ docker compose logs app          # Lihat error detail
$ docker compose down
$ docker compose up -d
$ bash deploy.sh lagi

Kalau Container Crash:
------------------------------
$ docker compose ps                # Check status
$ docker compose logs app          # Lihat error
$ docker compose restart app       # Restart
$ docker compose ps

Kalau Blank Page setelah update:
------------------------------
Biasanya karena frontend tidak ter-build. Cek:

$ ls public/build/manifest.json
$ npm run build
$ docker exec zinusit-app php artisan view:clear
$ bash deploy.sh
