## Docker Deployment Notes

### Migration Steps
1. Build Docker image with cleaned codebase
2. Run migrations: `php artisan migrate`
   - Will drop backup_monthly table
3. Seed any required data
4. Set up cron job for temp cleanup (optional but recommended)

### Environment Setup
```bash
# Copy production config
cp .env.production .env

# Generate app key if not present
php artisan key:generate

# Run migrations
php artisan migrate

# Cache configurations (recommended for production)
php artisan config:cache
php artisan route:cache
php artisan view:cache
```

### Cron Job (Recommended)
Add to crontab in Docker container:
```bash
# Clean temporary directories daily at 2 AM
0 2 * * * php /app/artisan cleanup:temp-directories
```

Or add to Laravel scheduler in `app/Console/Kernel.php`:
```php
$schedule->command('cleanup:temp-directories')->daily();
```

### Storage Setup
Ensure Docker volume mounts:
```yaml
volumes:
  - ./storage:/app/storage
  - ./bootstrap/cache:/app/bootstrap/cache
```
