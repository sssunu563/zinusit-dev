KEYBOARD SHORTCUTS (Baru):
═════════════════════════

  Alt+M       = Mark as MATCH (hijau)
  Alt+D       = Mark as MISMATCH (kuning)
  Alt+X       = Mark as MISSING (merah)
  Alt+Enter   = Submit verification

  Contoh workflow:
  1. Scan asset        ▶ "ABC123" muncul di form
  2. Tekan Alt+M       ▶ Status jadi MATCH
  3. Tekan Alt+Enter   ▶ Submit & auto-reset
  4. Ready scan lagi   ▶ ~2-3 detik per item!

  Dengan barcode scanner hardware: SANGAT CEPAT! 🚀

YANG TERJADI DI BACKEND SAAT SAVE:
═════════════════════════════════════

  POST /audit/123/verify
  {
    snipeit_asset_id: 123,
    asset_tag: "ABC123",
    serial: "ABC123DEF456",
    status: "Match",
    physical_location: "Gudang 1",
    physical_user: "Budi Santoso",
    note: "",
    expected_location: "Gudang 1",
    expected_user: "Budi Santoso"
  }

  Processing:
  1. ✓ Validate semua field
  2. ✓ Cek duplicate
  3. ✓ Create/Update audit_items record
  4. ✓ Catat: verifier = logged-in user
  5. ✓ Catat: verified_at = sekarang
  6. ✓ IF Match: Update Snipe-IT last_audit_date
  7. ✓ Log action untuk audit trail
  8. ✓ Return success

  Response: { success: true, item: {...} }

  Frontend:
  - Reload data
  - Clear form
  - Auto-focus input
  - Ready untuk aset berikutnya!
